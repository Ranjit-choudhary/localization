Esta opción fuerza un valor DPI específico para las fuentes. Puede ser útil cuando el DPI real del hardware no se detecta correctamente y también se usa incorrectamente con frecuencia cuando se usan fuentes de baja calidad que no se ven bien con valores DPI distintos de 96 o 120 DPI. Generalmente se desaconseja el uso de esta opción. Para seleccionar el valor DPI adecuado, una mejor opción es configurarlo explícitamente para todo el servidor X si es posible (por ejemplo, DisplaySize en xorg.conf o agregar el valor -dpi a ServerLocalArgs= en $KDEDIR/share/config/kdm/kdmrc). Cuando las fuentes no se renderizan correctamente con el valor DPI real, se deben usar mejores fuentes o se debe verificar la configuración de sugerencias de fuentes.
